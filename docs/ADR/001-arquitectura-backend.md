\# ADR-001 - Arquitectura Backend



\## Estado

Aceptado



\## Contexto



LeadFlow será una plataforma SaaS con múltiples módulos

(CRM, IA, Automatizaciones, Dashboard, WhatsApp).



\## Decisión



Se adopta una arquitectura por capas:



\- Routers

\- Services

\- Repositories

\- Models

\- Schemas

\- Database



\## Consecuencias



\- Mayor mantenibilidad.

\- Separación de responsabilidades.

\- Escalabilidad.

\- Facilita pruebas unitarias.
